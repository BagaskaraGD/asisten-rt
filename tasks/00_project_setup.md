# Task 00: Project Setup

## Goal
Setup project Next.js App Router dengan TypeScript, Tailwind, dan struktur awal AsistenRT.

## Requirements
- Next.js App Router
- TypeScript
- Tailwind
- ESLint
- Folder structure rapi
- Tidak implement fitur AI dulu

## Expected Output
- Project bisa run dengan `npm run dev`
- Home page sederhana
- Dashboard placeholder
- Chat simulator placeholder
- Admin placeholder

## Do Not

- Jangan integrasi WhatsApp
- Jangan buat fitur pembayaran

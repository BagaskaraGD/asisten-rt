# MVP Scope v1

## Goal

Membuat aplikasi web AsistenRT versi MVP yang membantu administrasi RT/RW melalui chat simulator berbasis AI.

## Primary Users

1. Warga
2. Admin RT
3. Super Admin

## In Scope

### Warga
- Menggunakan chat simulator
- Bertanya FAQ RT
- Mengajukan draft surat
- Melaporkan keluhan lingkungan
- Melihat status permintaan sederhana

### Admin RT
- Login
- Mengelola profil RT
- Mengelola FAQ
- Mengelola template surat
- Melihat permintaan surat
- Approve/reject draft surat
- Melihat laporan keluhan
- Mengubah status keluhan

### Super Admin
- Membuat RT dummy/pilot
- Membuat admin RT
- Melihat usage dasar

## Out of Scope

- WhatsApp integration
- Payment/iuran
- Tanda tangan digital
- OCR dokumen
- Mobile native
- Integrasi kelurahan
- Multi-tenant billing
